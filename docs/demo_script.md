# Demo Script

1. Open `http://localhost:5178` and show SmartHome dashboard
2. Open `http://localhost:8580/docs` and inspect gateway workflow endpoints
3. Start 2FA challenge and verify token
4. Run voice command from UI and show updated device state
5. Trigger scenario `SCN-AWAY` and show command log growth
6. Show KPI panel for command latency, availability, and voice accuracy
7. Show anomaly and notification sections
8. Show integrations list and weather feed
