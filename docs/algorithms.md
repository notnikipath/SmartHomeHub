# Algorithms

## Voice intent parsing

A lightweight rule parser maps natural language phrases to actions and device names. It supports English and Russian trigger tokens and returns confidence scores.

## Energy forecasting

The monitoring service applies a moving average with trend correction over recent samples to estimate 24-hour consumption.

## Anomaly detection

An anomaly score is based on z-score logic over recent values. When the score exceeds threshold, a critical event is raised.

## Behavior learning

Frequent command patterns are grouped by room and action to propose reusable automation scenarios.

## Command latency estimation

Estimated latency depends on protocol baseline, queue depth penalty, and edge processing bonus.
